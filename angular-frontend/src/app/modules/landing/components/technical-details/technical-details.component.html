Detalles técnicos del proyecto

Funcionalidades, tecnologías y buenas prácticas aplicadas durante el desarrollo del proyecto y adquiridas durante mis prácticas profesionales de Desarrollo de Aplicaciones Web.

Symfony · PostgreSQL · Docker

Backend

  • ● Desarrollo y prueba de APIs REST con Symfony.
  • ● Implementación de autenticación JWT y control de acceso basado en roles (RBAC).
  • ● Diseño y optimización de bases de datos PostgreSQL.
  • ● Creación de triggers, procedimientos almacenados y vistas para automatizar procesos.
  • ● Creación de servicios reutilizables para centralizar la lógica de negocio.
  • ● Validación y documentación de endpoints utilizando Postman.
  • ● Despliegue de servicios mediante Docker y gestión de entornos.
Angular · TypeScript · TailwindCSS

Frontend

  • ● Implementación de una arquitectura modular en Angular.
  • ● Desarrollo de servicios para el consumo de APIs REST.
  • ● Desarrollo de flujos de usuario como login, registro, reservas y pagos.
  • ● Diseño de interfaces responsive mediante Angular y TailwindCSS.
  • ● Centralización de errores y notificaciones mediante un servicio de toasts reutilizable.
  • ● Refactorización de Observables y mejora de la organización del código.
  • ● Aplicación de buenas prácticas orientadas a mejorar la mantenibilidad y escalabilidad.

Stack utilizado

Symfony PHP PostgreSQL Angular TypeScript TailwindCSS Docker JWT Postman REST API
