Proyecto demostrativo

De mis prácticas DAW a un proyecto Full Stack

Esta aplicación web tiene un propósito exclusivamente demostrativo. Ha sido desarrollada para mostrar de forma práctica las habilidades y conocimientos que adquirí durante mis prácticas profesionales del ciclo de Desarrollo de Aplicaciones Web (DAW).

El proyecto parte de una aplicación desarrollada durante mis prácticas y ha sido adaptado posteriormente a una temática de Los Vengadores, manteniendo y ampliando su arquitectura y funcionalidades con fines de portfolio.

Incluye desarrollo backend con Symfony y PostgreSQL, creación y consumo de APIs REST, autenticación JWT y control de acceso por roles, desarrollo frontend con Angular y TailwindCSS, gestión de formularios, servicios reutilizables, manejo centralizado de errores y despliegue mediante Docker.
